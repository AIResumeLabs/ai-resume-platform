# AI Resume Intelligence Platform

An AI-powered Applicant Tracking System (ATS) that automates resume screening and candidate matching using NLP and semantic search.

## Features

* 📄 Resume PDF parsing
* 🧠 Skill, email, and phone extraction
* 💾 Structured candidate storage
* 📋 Job description management
* 🔍 Semantic candidate-job matching (in progress)
* 📊 Ranking engine and HR dashboard (planned)

## Tech Stack

* **Backend:** FastAPI, SQLAlchemy
* **Database:** SQLite (PostgreSQL planned)
* **NLP:** spaCy
* **PDF Processing:** pdfplumber
* **ML:** Sentence Transformers (planned)
* **Frontend:** React (planned)

## Status

🚧 Currently under active development as a collaborative learning project.
